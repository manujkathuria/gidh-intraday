## Eleventh Memory

Day 11 taught the second execution layer:

- Long selection improved when we demanded current morning strength.
- Shorts need market-regime permission, not just one ugly early candle.
- Split groups require stock-level acceptance; `AUBANK` and `BANKINDIA` can
  tell opposite stories on the same day.
- Some momentum trades need digestion time; `KFINTECH` punished an exit that
  was too mechanical.
- Lunch lockdown is still useful for no new trades, but we should distinguish
  between opening fresh trades and holding an already valid winner.

The Day 12 question:

Can we add an exit rule that lets clean winners survive the 11:30 digestion
window, while still preventing boredom trades during lunch?
